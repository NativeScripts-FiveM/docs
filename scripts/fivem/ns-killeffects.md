All props are custom models (no vanilla props, no particles): smooth shapes and real font text (Archivo, Inter, Noto Sans CJK — all SIL OFL). They are spawned as **local, non-networked objects** on each client, so an effect costs no network entities.

## Performance: baked effects

Every effect is **one animated prop**: its parts are bones and the whole motion is a clip (`stream/ns_kfx_anim_<id>.ycd`) that the game engine plays with `PlayEntityAnim`. The script only spawns the prop, sets its alpha while it fades in and out, and deletes it — there is no per-part, per-frame script work.

If a clip ever fails to start, the effect falls back on its own to the per-part Lua animation (`client/effects/*.lua`, one `SetEntityMatrix` per part per frame) and a message is printed to F8.

**Screen hits.** An effect may define `screen = { at, kind, shake, amplitude }` (only `punch` does): the killer's client — and a player testing the effect from the menu — shakes the gameplay camera and shows a full-screen NUI overlay `at` seconds after the effect starts. The server tells each receiving client only whether it is the killer (a true/false flag, never the killer's id); nobody else gets the overlay.

Trade-offs of baking: props that face the camera are baked facing the killer (other viewers see them at an angle), parts that fade on their own shrink out instead, and each effect plays the same recorded variation every time.

## Requirements

- OneSync (the server checks `GetPedSourceOfDeath` before an effect plays).
- Nothing else: no framework, no database, no other resource. If ox_lib, ESX, QBCore, Qbox or vRP is running it is used for notifications (and ox_lib's theme colours the menu); without them the game's own notification feed is used. Picks are stored in the resource's KVP by Rockstar license.

## Installation

1. Drop `ns-killeffects` into your server `resources` folder.
2. Add `ensure ns-killeffects` to `server.cfg`.

## Configuration

Everything a server owner sets is in `config.lua`:

| Setting | Default | Meaning |
|---|---|---|
| `Config.ShowToEveryone` | `true` | `true`: every player nearby sees a kill effect. `false`: only the killer sees their own effect |
| `Config.BroadcastRadius` | `200.0` | With `ShowToEveryone = true`: how far from the victim (m) players still receive the effect |
| `Config.MenuKey` | `''` | Default key for the menu (players can rebind it in Settings › Key Bindings › FiveM) |
| `Config.UI.accent` | `nil` | Menu accent colour, e.g. `'#E11D48'`; `nil` follows ox_lib's theme, else blue |
| `Config.Effects` | 53 effects, all on | The menu shows them in this order. `enabled = false` turns one off (out of the menu, can no longer be picked); move a line to reorder, edit `label` / `description` to rename. No numbers to fix |
| `Config.Messages` | English | Notification texts |

```lua
Config.Effects = {
    { id = 'butterfly', enabled = true,  label = 'Ember Butterfly', description = '...' },
    { id = 'thunder',   enabled = false, label = 'Thunder Strike',  description = '...' },  -- off
    ...
}
```

Players who had an effect that gets turned off simply have none until they pick another. New players have no effect until they pick one in the menu. Players can hide every kill effect on their own screen with the switch at the bottom of the menu.

## Commands

| Command | Who | Does |
|---|---|---|
| `/killfx` | everyone | Opens / closes the menu: live preview, Equip, Test, search (ranks the closest matches first instead of hiding rows) and the hide switch. Test — and Equip, once the server confirms — plays the effect on your screen only, 4 m away and off to the side of your view so your character does not hide it. Keys: ↑/↓ select, Enter equip, Esc close. You can keep walking while it is open: mouse look, weapons, the GTA phone, cfx chat and pause are blocked, and typing in the search field stops movement. Key mappings of other resources (inventory, radial menu, custom phone) still work. Bindable key: `Config.MenuKey` / Settings › Key Bindings › FiveM |
| `/killfx <id\|none>` | everyone | Picks your kill effect directly; saved per license |

## How a kill becomes an effect

1. The killer's client sees `CEventNetworkEntityDamage` with itself as the attacker and a dead victim, and reports the victim's network id.
2. The server confirms the victim is a ped, that the reporter is its source of death, and that they are within 400 m. Reports are rate-limited per killer and de-duplicated per victim.
3. The server sends the killer's equipped effect to every player in the same routing bucket within `Config.BroadcastRadius` — or, with `Config.ShowToEveryone = false`, to the killer only (nobody else sees it).
4. Each client plays it locally (skipped more than 150 m from the camera, or when 4 effects are already playing on that client). On sloped ground the effect tilts to match the surface (up to 15°), so flat parts like puddles and scorch marks never sink into the high side.

Only player kills trigger effects (checked on both the killer's client and the server); NPC kills never do. To see an effect without a kill, use Test in the menu.

## Exports

For shops, VIP systems, game modes and kill feeds. Effect ids are the keys of `Config.Effects`; `'none'` means no effect.

**Server**

| Export | Returns | Does |
|---|---|---|
| `getEffects()` | `{ { id, label, description }, ... }` | Every effect, in menu order |
| `isEffect(id)` | `boolean` | Whether `id` is an effect in `Config.Effects` |
| `getEquippedEffect(source)` | `id` / `'none'` / `nil` | The player's effect (`nil` if not connected) |
| `setEquippedEffect(source, id)` | `boolean` | Sets and saves the player's effect (`'none'` clears it); their open menu updates |
| `playKillEffect(killer, coords, victimNetId?, effectId?)` | `id` / `false` | Plays the killer's effect at `coords` with the normal rules (`Config.ShowToEveryone`) — for modes that detect kills themselves. `effectId` plays that effect instead of the killer's pick |
| `playAt(id, coords, from?, bucket?, mode?, victimNetId?, killer?)` | `boolean` | Plays any effect. `from` sets the direction, `killer` gets the screen hit; with `Config.ShowToEveryone = false` only `killer` sees it (nobody without one) |

```lua
local fx = exports['ns-killeffects']
fx:setEquippedEffect(source, 'thunder')                 -- e.g. after a purchase
fx:playKillEffect(killerSource, GetEntityCoords(victimPed))
```

**Client**

| Export | Does |
|---|---|
| `openMenu()` / `closeMenu()` / `isMenuOpen()` | Open the menu from your own UI (e.g. a VIP menu) |
| `getEquippedEffect()` | This player's effect (as last sent by the server) |
| `isHidden()` / `setHidden(bool)` | Hide every kill effect on this player's screen (saved) |
| `play(id, coords, from?)` | Plays an effect on this screen only |

**Server events** — server-side only: listen with `AddEventHandler`, never `RegisterNetEvent` (that would let clients fake them).

| Event | Arguments | When |
|---|---|---|
| `ns-killeffects:server:effectPlayed` | `killer, effectId, coords, victimNetId` | A kill effect was sent |
| `ns-killeffects:server:equipped` | `source, effectId` | A player's effect changed (menu, `/killfx` or export) |

## Menu

`ui/` is a React + Vite app on the `ns-ui` kit (copied into `ui/src/kit`); `npm run build` in `ui/` writes `html/`. Preview media live in `ui/public/previews/` (`<id>.webm`, `.webp`, `-thumb.webp`). The accent follows `Config.UI.accent`, else the server's ox_lib theme.
